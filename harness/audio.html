Audio harness

Every sound below is synthesised at runtime from oscillators, filters and procedurally generated noise. There are no audio files in this project and no audio bytes in the bundle. Browsers block audio until a real gesture, so unlock first.

Game events

These fire real GameEvent payloads through the event bus. Nothing calls the audio system directly — this is exactly the path gameplay uses.

Voices

Music — intensity layers

Layers add and drop parts on the next bar line; they are not crossfaded stems. Boredom eats the arrangement away until only a single sustained tone is left.
